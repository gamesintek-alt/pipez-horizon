A native mod port of [Pipez](https://curseforge.com) (originally created by **henkelmax**) for [Horizon](https://github.com) — a Rust-based implementation of **Minecraft: Java Edition**.

This modification adds simple, high-performance, and configurable pipes for transporting items, fluids, and energy between blocks and machines.

## 📦 Repository Contents

* `pipez.hnmod` — compiled Horizon native mod bundle.
* `mixins/pipez` — Rust source mixins that hook into and extend the game logic.
* `horizon-native.json` — configuration manifest for native module integration.

## 🚀 Installation

You can install this mod in the [Horizon Launcher](https://github.com/releases) in two ways:

1. **Via GitHub Link (Recommended):** Copy this repository URL (`https://github.com`) and paste it directly into the launcher to install.
2. **Via File:** Download `pipez.hnmod` from this repository and drop it into the **Native Mods** section/folder in the launcher.

After adding the mod, build/compile your instance in the launcher and start the game.

## 🛠 Port Features

* Built as a native Rust mod (`.hnmod`) for [Horizon](https://github.com).
* Preserves core mechanics of the original [Pipez](https://curseforge.com) mod (filters, pipe upgrades, extraction modes).
